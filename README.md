# modern-warfare-3-decomp

Decompilation of Call of Duty: Modern Warfare 3 (2011, IW5), targeting the Microsoft Store PC build (x64), multiplayer
first. The Xbox 360 title update 1 builds, which shipped with full PDBs and linker MAPs, are the references.

- `AGENTS.md`: rules, layout, status ladder, address format
- `STATUS.md`: progress, generated from `analysis/` and `records/`
- `target.toml`: every build, with its R2 location and hashes
- `docs/`: builds, the Xbox 360 references, the Store build, matching, verification, roadmap

Game files are not in this repository.
